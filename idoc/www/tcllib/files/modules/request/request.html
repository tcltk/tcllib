request

request is a TclOO wrapper for the standard Tcl http package that stores request state and executes HTTP/HTTPS requests.

Synopsis

package require request
request create client
client configure -method GET -url https://www.example.com
set body [client execute]

Attributes

  • method — HTTP method, e.g. GET, POST.
  • url — Request URL.
  • body — Request body payload.
  • headers — Header list for the request.
  • opts — Additional options forwarded to the http package.

Methods

configure ?options?
Set stored request attributes, or return a dictionary of current settings when called without arguments.
cget attr
Return the value of the named attribute. Valid keys include method, url, body, headers, opts, lastBody, lastCode, lastStatus, lastMeta, and lastToken.
execute
Execute the stored request. Throws an exception on failure or if the HTTP status is not 2xx. Returns the response body on success.
request method url ?body? ?headers? ?opts?
Perform a one-shot HTTP request and return a list containing body, code, status, headers, and token.
get url ?headers? ?opts?
Convenience wrapper for GET requests.
post url ?body? ?headers? ?opts?
Convenience wrapper for POST requests.
lastResponse
Return the last response details as a list.

Examples

package require request
request create client
client configure -method GET -url https://www.example.com
set body [client execute]
puts $body
package require request
request create client -method POST -url https://api.example.com/submit \
    -body {name=alice&action=save} -headers {Content-Type application/x-www-form-urlencoded}
set body [client execute]
puts $body
package require request
request create client
client configure {
    method POST
    url https://api.example.com/submit
    headers {Content-Type application/json}
    body {"name":"alice"}
}
try {
    set body [client execute]
    puts $body
} on error {type msg} {
    puts stderr "Request failed ($type): $msg"
}
